GPI — screen snapshots

Static HTML + CSS of each prototype screen, for the dev team to reference markup and styling.

How to use a snapshot

  1. Click a screen below — it opens the rendered page.
  2. Save it: press Cmd/Ctrl + S → choose “Webpage, HTML Only”. You get one self-contained .html file (markup + all CSS inlined).
  3. Read the code: open that file in your editor, or View Source (Cmd/Ctrl + U). Styles live in the single <style> block.
  4. Inspect an element: right-click it → Inspect to see its exact HTML + CSS.

These are static snapshots — not interactive, and wizard steps show the default (empty) state. Class names (gpi-*, b2b-*) are the design-system tokens. Keep an internet connection so images and the Georgian font render.
